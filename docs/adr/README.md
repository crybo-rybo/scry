# Architecture decision records

Dated records of the decisions that shaped Scry, newest last. Each captures the
context, decision, and consequences behind one fork in the road. Records are
kept as written: superseded or amended decisions are marked in their status
lines rather than rewritten, so the history stays trustworthy.

Milestone labels in older records (M0–M5) refer to Scry's pre-release
development stages and survive here as historical context, as does the
working label "v0.0.1" in records that predate the first release — the
release it refers to shipped as v0.1.0. For the current,
binding behavior of the library, read [REQUIREMENTS.md](../../REQUIREMENTS.md);
where an older record and the register disagree, the register wins.

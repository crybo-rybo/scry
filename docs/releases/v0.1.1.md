# Scry v0.1.1

Scry v0.1.1 adds a public typed-to-JSON boundary to the optional and
experimental C++26 reflection component.

## Added

- `scry::reflection::encode(const T&)` accepts all supported reflected values
  and returns canonical `Json` that Scry owns. It does not register or invoke a
  tool.
- Direct encoding and reflected tool results use the same closed recursive
  value mapping. The direct output is the same as the JSON that reflected tool
  dispatch sends. This includes the canonical number spelling.
- Reflection codec and dispatch tests, a consumer of the installed package, and
  the reflection example cover the public API.

## Compatibility

- This release only adds new items, and all of its changes are in
  `scry::reflection`. The stable C++23 core API and the core-only package do
  not change.
- The reflection component is still experimental. GCC 16 or newer is
  necessary for it.
- Encoded values are canonical in this Scry release. But they are not a
  versioned persistence format, and they have no byte guarantee across
  versions.

Scry v0.1.1 has no breaking changes.

## Upgrade

Update FetchContent pins to `v0.1.1` or request
`find_package(scry 0.1.1 CONFIG REQUIRED)`. Current core consumers do not have
to change their source.

Scry is still pre-1.0. The API, the ABI, and the formats for persisted
conversations can change between releases.

[Full comparison](https://github.com/crybo-rybo/scry/compare/v0.1.0...v0.1.1)

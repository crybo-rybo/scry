# Scry v0.1.1

Scry v0.1.1 adds a public typed-to-JSON boundary to the optional,
experimental C++26 reflection component.

## Added

- `scry::reflection::encode(const T&)` accepts every supported reflected value
  and returns canonical Scry-owned `Json` without registering or invoking a
  tool.
- Direct encoding and reflected tool results share the same closed recursive
  value mapping. Direct output matches the JSON sent by reflected tool
  dispatch, including canonical number spelling.
- The public API is covered by reflection codec and dispatch tests, an
  installed-package consumer, and the reflection example.

## Compatibility

- This release is additive and confined to `scry::reflection`; the stable
  C++23 core API and core-only package remain unchanged.
- The reflection component remains experimental and requires GCC 16 or newer.
- Encoded values are canonical within this Scry release but are not a
  versioned persistence format and carry no cross-version byte guarantee.

There are no breaking changes in v0.1.1.

## Upgrade

Update FetchContent pins to `v0.1.1` or request
`find_package(scry 0.1.1 CONFIG REQUIRED)`. Existing core consumers require no
source changes.

Scry remains pre-1.0: API, ABI, and persisted conversation formats may change
between releases.
